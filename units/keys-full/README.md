# keys-full

One of three units that decide what opens OmaCast. Exactly one at a time: each
names the other two in `conflicts`, so `bo` refuses the second.

The invasive one. `Super+K` opens OmaCast, and nothing else opens a launcher:
`Super+Space` and `Super+Alt+Space` are unbound.

The keybindings cheatsheet loses `Super+K` and moves to `Super+H`, for help.

If that turns out to be too much, the Omarchy menu still has its bar icon and
`Super+Shift+F12`, so you can reach it and undo this without editing config.

| Key | Before | After |
|---|---|---|
| `Super+K` | Keybindings | OmaCast |
| `Super+H` | free | Keybindings |
| `Super+Space` | Omarchy menu | unbound |
| `Super+Alt+Space` | Apps menu | unbound |
